# Developer Portfolio Template

Modern portfolio starter built with Astro, React, and Tailwind CSS.

## Features

- Built with Astro and React islands
- Responsive project, about, experience, and contact pages
- Dynamic project filtering and load-more behavior
- Template copy that is ready to replace with your own profile content

## Tech Stack

- [Astro](https://astro.build/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- JavaScript and TypeScript
- [Vite](https://vite.dev/)

## Commands

All commands are run from the project root:

| Command | Action |
| :-- | :-- |
| `pnpm install` | Install dependencies |
| `pnpm run dev` | Start the local dev server at `localhost:4321` |
| `pnpm run build` | Build the production site to `./dist/` |
| `pnpm run preview` | Preview the production build locally |
| `pnpm exec astro check` | Run Astro type and diagnostics checks |
